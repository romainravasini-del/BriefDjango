ATTRIBUTS DES FORMULAIRES method="post" Les données partent dans le corps de la requête (jamais dans l'URL), indispensable pour un mot de passe. Pas d'attribut action : le formulaire est renvoyé vers l'adresse de la page actuelle. type="submit" Le bouton envoie le formulaire. name="action" value="connexion" / value="inscription" Les deux formulaires arrivent à la même vue. La valeur du bouton cliqué est transmise dans la requête (request.POST["action"]) : la vue s'en sert pour savoir quel formulaire traiter. CLASSES TAILWIND UTILISÉES Tailwind fonctionne avec des classes "utilitaires" : chaque classe applique une règle CSS. On les combine directement dans l'attribut class. Rappels d'échelle : - Espacements : 1 unité = 0,25 rem (donc 4 = 1 rem = 16 px, 8 = 2 rem). - Préfixes responsive (mobile d'abord) : sans préfixe = toutes les tailles, "md:" = à partir de 768 px. - Préfixe "hover:" = appliqué seulement au survol de la souris. Typographie text-5xl / text-2xl Taille du texte (très grand pour le titre de la page, grand pour les titres de carte). font-bold / font-semibold Graisse : gras / demi-gras. text-center Texte centré. text-slate-500/800 Couleur du texte : gris-bleu, du plus clair (500) au plus foncé (800). text-white Texte blanc (sur le bouton). Mise en page max-w-3xl Largeur maximale du contenu (48 rem, environ 770 px). mx-auto Marges gauche/droite automatiques = bloc centré. w-full Largeur à 100 % du parent (le bouton occupe toute la largeur de sa carte). Grille grid Active la grille CSS. grid-cols-1 Une colonne (mobile : les cartes s'empilent). md:grid-cols-2 Deux colonnes dès 768 px (cartes côte à côte). gap-8 Espace entre les cellules de la grille.
