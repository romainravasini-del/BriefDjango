FORMULAIRES method="get" Filtres et recherche : les choix passent dans l'URL (?activite=2&date_debut=...). Page partageable, aucune modification en base. method="post" Toute action qui MODIFIE des données (annuler, s'inscrire, changer d'état, se déconnecter). Jamais en GET. input hidden Valeur envoyée sans être affichée (ex. le nouvel état). Elle peut être modifiée par un utilisateur malveillant : la vue doit donc revérifier chaque transition. GRAPHIQUE Chart.js (bibliothèque JavaScript chargée depuis un CDN) dessine un graphique en anneau dans la balise . Les nombres viennent de Django, injectés dans le script. CLASSES TAILWIND UTILISÉES Chaque classe applique UNE règle CSS ; on les combine dans l'attribut class. Rappels d'échelle : - Espacements : 1 unité = 0,25 rem (4 = 16 px, 8 = 32 px). - Préfixes responsive (mobile d'abord) : sans préfixe = partout, "md:" = dès 768 px, "lg:" = dès 1024 px. - "hover:" = au survol ; "focus:" = quand le champ est sélectionné. - Couleurs : famille (sky, amber, emerald, red, rose, slate...) + intensité (50 très clair ... 900 très foncé). "/95" ou "/80" = opacité en %. - Valeurs entre crochets, ex. max-h-[32rem] : valeur personnalisée. Typographie text-5xl / 2xl / lg / sm / xs Taille du texte, de très grand à petit. font-bold / semibold Graisse du texte. uppercase Texte en majuscules. text-center Texte centré. text-- Couleur du texte. Mise en page max-w-6xl / max-w-md Largeur maximale du bloc. max-h-[32rem] + overflow-y-auto Hauteur limitée (512 px) avec défilement vertical quand le contenu dépasse. mx-auto Bloc centré horizontalement. w-full Largeur à 100 % du parent. block Le label passe au-dessus du champ. flex / flex-wrap Éléments alignés sur une ligne (wrap : retour à la ligne si pas de place). justify-between Éléments répartis aux extrémités. items-start / items-end Alignement vertical en haut / en bas. shrink-0 Empêche le badge de se rétrécir. flex-1 L'élément prend la place restante. Grille grid, grid-cols-1/2/3/5 Nombre de colonnes (avec préfixes md:/lg:). md:grid-cols-[1fr_1fr_auto] Colonnes personnalisées : 1fr = part égale de l'espace libre, auto = largeur du contenu. gap-1.5 / 2 / 4 / 6 / 10 Espace entre éléments. space-y-3 / space-y-4 Espace vertical entre enfants empilés. Espacements p-/px-/py- Padding interne (tous côtés / horizontal / vertical). m-/mt-/mb- Marges extérieures (haut / bas). Apparence bg-- Fond. Convention des états dans cette page : sky = inscrit, amber = liste d'attente, emerald = présent, red = absent, slate = annulé. border / border- Bordure fine de 1 px. rounded / lg / xl / full Coins arrondis (full = pilule ou cercle). shadow-sm / shadow-md Ombre portée légère / moyenne. opacity-90 Légère transparence (effet "archive"). transition Animation douce des changements au survol. focus:outline-none focus:ring-2 focus:ring-sky-400 Retire le contour par défaut d'un champ et le remplace par un halo bleu quand il est actif. {% endcomment %} {% block content %}
